# Security and privacy policy

## Reporting

Use GitHub Security Advisories to report vulnerabilities privately. Do not include a real Service Desk export in a report.

## Data handling

- Processing is local and makes no network requests.
- Personal-data masking is enabled by default.
- HTML and JSON reports contain aggregate metadata only, not ticket rows.
- Review CSV files can still contain unrecognized sensitive formats.
- Disable masking only in an appropriately protected environment.
- Treat source and output files as confidential operational data.

The masking rules cover conventional email addresses and common international or local phone-number formatting. They are risk-reduction controls, not a complete data-loss-prevention system.

## Supported versions

Security fixes are provided for the latest release on the default branch.
